# 名前表示 v1 現地観察チェックリスト

目的は、数字や予約状態を追加する前に「名前を確定した参加者が、自分の表示を発見できるか」を測ること。
撮影率だけを成功指標にしない。

## 1セッションごとの記録

- 日時・場所・おおよその混雑度
- ソロ参加 / 2人組 / 3〜4人組 / 5人以上
- 名前確定後にDOOHを見上げたか
- 自分の名前を発見できたか（本人の発話・指さし・同行者への反応で判断）
- 指さし、笑顔、「出た」などの発話があったか
- カメラを構えたか
- 名前表示前にその場を離れたか
- スマホとDOOHの視線を何度往復したか
- 表示後に参加証へ戻ったか
- 自由記述（迷い、照れ、通信待ち、同行者の補助など）

## 集計

- 見上げ率 = 見上げた人数 / 名前確定人数
- 発見率 = 自分の名前を発見できた人数 / 名前確定人数
- 表示前離脱率 = 表示前に離れた人数 / 名前確定人数
- 指さし・発話率、撮影率、参加証復帰率
- 上記をソロ / グループ別に比較

## v2を検討する条件

次のいずれかが観察された場合のみ、slot確定・順番表示・直前カウントダウン・認証付きleader leaseを検討する。

- 発見率が低い
- 見上げる前に名前表示が終わる
- 同時参加で個人リビールが混線する
- ソロ参加者の発見率だけが明確に低い
- 名前確定から表示までの待ち時間の分散が大きい

v1ではDOOHからFirebaseへの表示状態書き戻しを行わない。プレビューやクローンタブが本番予約を消費する事故を避けるため、書き戻しは認証とleader leaseを同時に設計できるv2まで導入しない。
